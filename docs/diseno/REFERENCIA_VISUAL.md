# Referencia visual de VEXOR

El mockup general proporcionado por el usuario es la referencia visual de las pantallas presentes y siguientes: [ver imagen](referencias/vexor-mockup-general.png).

Mantener el estilo claro, la navegación lateral, las tarjetas de indicadores, los paneles de gráficos y actividad, y las listas con fotos. En celular se mantiene la navegación inferior y se adapta el contenido al ancho disponible.

Las decisiones funcionales y de navegación ya aprobadas prevalecen sobre los datos ilustrativos del mockup. La cuenta y cerrar sesión siguen abajo; no se recupera el header superior descartado. No se inventan cifras de ventas, pagos, sincronización ni funcionalidades pendientes para imitar la imagen. Cada nuevo módulo se desarrolla dentro del alcance solicitado.
